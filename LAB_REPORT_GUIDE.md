## 2. What data did you use?

- Name of the dataset
- What one row represents

## 3. What did you do in R?

List the main things you did.

Examples:

- Made a frequency table
- Calculated mean and standard deviation
- Created a histogram

- Calculated correlation

- Found a confidence interval
- Performed a hypothesis test

Do not copy all of your R code here. Your full code should be in your Colab notebook.

## 4. Main Results

Write the most important results from the lab.

For example:

- Mean = ______
- Median = ______
- Standard deviation = ______
- Probability = ______

- Confidence interval = ______
- p-value = ______

Only include the results that apply to this week's lab.

## 5. Graph or Table

Include **one important graph or table** from your Colab notebook.

Examples:

- Bar chart
- Histogram
- Boxplot
- Scatterplot
- Frequency table

Under the graph or table, write **1–2 sentences** explaining what it shows.

---

## 6. What do the results mean?

Explain the result in your own words.

Do not only write numbers.

Example:

Instead of:

## 7. Conclusion

Write 2–3 sentences.

Answer:

- What did you learn from the data?
